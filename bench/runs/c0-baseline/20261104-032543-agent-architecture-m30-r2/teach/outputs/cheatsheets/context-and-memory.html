Context and memory in an agent

From Lesson 1. Objective O3.

Key terms

TermMeaning
ContextAll the text sent to the model in one call: system prompt, tool definitions, messages, tool results.
Context windowThe maximum size of one call, including the reply. It is not storage.
Context rotRecall gets worse as the context gets longer.
CompactionSummarize a long history and start a new window from the summary.
Short-term memoryThe message history of one conversation.
Long-term memoryFacts saved outside the context that later sessions can load.
RetrievalFetching only the relevant chunk of a large source into the context when needed.

Rules of thumb

  • Each call is separate: the program resends the history, so a big tool result is paid for on every later call.
  • Input tokens for a request = the sum of every call's input, not just the last one.
  • A new session starts empty. Only what you saved outside the context can come back.
