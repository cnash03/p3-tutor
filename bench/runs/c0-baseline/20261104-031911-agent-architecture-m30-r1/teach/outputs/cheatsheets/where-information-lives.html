Where information lives in an agent

From Lesson 1. The model is stateless: the program supplies all state.

Rules of thumb

  • Input tokens for a run = the sum of the full context at every call, not the text counted once.
  • A large tool result is re-sent on every later call: clear it once used.
  • More context is not better: cost rises and recall falls (context rot).
  • Save small durable facts, not raw tool output.
  • Memory tools are client-side: the model requests, the program writes.

Terms

Context: tokens sent in one request. Context window: the limit on them. Compaction: summarize and continue. Retrieval: fetch only relevant sections.
